# Reference material

Material EVA Admin is compared against. Used to judge M3: a screen is correct
when it matches what the manuals and the archived portal show, not merely when it
renders (D007).

The files themselves are gitignored — they are large and externally owned. This
index is tracked, so a missing file is visible rather than silently absent.

## Where things go

| Directory | Contents |
|---|---|
| `docs/reference/valgmedarbeiderportalen/` | Archived copies of valgmedarbeiderportalen |
| `docs/reference/manuals/` | Instruction manuals and system documentation, with screenshots |
